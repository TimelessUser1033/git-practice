# Документация REST API

Базовый URL: `https://example.com`

## 1. Получить список задач
- **Метод и путь:** `GET /tasks`
- **Описание:** Возвращает список всех созданных задач.
- **Пример ответа (`200 OK`):**
```json
[
  {
    "id": 1,
    "title": "Изучить Git и GitHub",
    "completed": true
  }
]
```

## 2. Создать новую задачу
- **Метод и путь:** `POST /tasks`
- **Тело запроса (`application/json`):**
```json
{
  "title": "Настроить CI/CD"
}
```
- **Пример ответа (`201 Created`):**
```json
{
  "id": 2,
  "title": "Настроить CI/CD",
  "completed": false
}
```
- **Возможные ошибки:** `400 Bad Request` — если поле `title` пустое или не передано.
