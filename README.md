# Git Practice

![Python CI](https://github.com)
![Python](https://shields.io)

Учебный репозиторий для отработки навыков работы с Git, GitHub, ветвлением, автотестами и документацией.

## Структура проекта

- `math_utils.py` — базовые математические функции (`add`, `multiply`)
- `test_math_utils.py` — модульные тесты на `pytest`
- `.github/workflows/ci.yml` — конфигурация автоматического тестирования в GitHub Actions

## Быстрый старт

```bash
git clone git@github.com:TimelessUser1033/git-practice.git
cd git-practice
pip install pytest
pytest
```
